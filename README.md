📱 Intern Chat App (Flutter + Firebase)

📌 Project Description

Intern Chat App is a real-time chat and call application developed using Flutter and Firebase.
This project allows users to sign up, log in, chat in real time, and access features like calls, profile, wallet, and settings.

This application was developed as part of an internship assignment to demonstrate Flutter development skills and Firebase integration.

---

🚀 Features

- User Authentication (Login & Signup using Firebase)
- Real-time Chat (Cloud Firestore)
- Call Screen UI
- Profile Page
- Wallet Page UI
- Settings Page
- Modern Dashboard UI
- Logout Functionality

---

🛠️ Technologies Used

- Flutter (Dart)
- Firebase Authentication
- Cloud Firestore Database
- Material UI

▶️ How to Run Project

1. Install Flutter SDK
2. Connect device or emulator
3. Open project in VS Code
4. Run command:

flutter pub get
flutter run

---

🔥 Firebase Configuration

This project uses Firebase Authentication and Firestore database.
Firebase is connected using firebase_options.dart.
